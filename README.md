# 🌱 Proyecto Capstone - Punto de Venta con Control de Inventario
**Plantitas donde la Fran**  

Este repositorio contiene el desarrollo del proyecto Capstone para el emprendimiento **“Plantitas donde la Fran”**, un negocio familiar dedicado a la venta de plantas.  
El objetivo es implementar un **sistema de Punto de Venta (POS) con control de inventario** que permita optimizar la gestión de ventas y existencias mediante una plataforma web.

---

## 🎯 Objetivo del proyecto
Desarrollar una plataforma web que:
- Permita registrar ventas de forma rápida y segura.  
- Lleve control del inventario en tiempo real.  
- Facilite la administración de productos, clientes y usuarios.  
- Sea escalable y fácil de usar para pequeños emprendimientos.
